🏋️ Treino Dark Mode

Projeto desenvolvido como exercício de HTML e CSS, com o objetivo de praticar a criação de uma interface moderna em Dark Mode.

A página apresenta uma divisão de treinos em A, B, C e D, com exercícios, séries, repetições e imagens ilustrativas.

🛠️ Tecnologias

HTML5

CSS3

Google Fonts

Font Awesome

Unsplash

🎯 Objetivo

Praticar conceitos de estruturação HTML, estilização CSS, organização de conteúdo e criação de interfaces responsivas.

Projeto desenvolvido para fins de estudo e prática de Front-End.
